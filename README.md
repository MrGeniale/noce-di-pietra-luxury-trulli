# Noce di Pietra – Luxury Trulli

Un’oasi di charme immersa nella quiete della Valle d’Itria, a pochi minuti da Alberobello.
Trulli autentici con vasca idromassaggio privata, camera padronale sotto la volta in pietra, cucina attrezzata e prenotazione diretta via WhatsApp.

## 🌟 Tecnologie
- **React 19** + **TypeScript**
- **Vite 8**
- **Tailwind CSS v4**
- **Framer Motion**
- **Lucide Icons**

## 🚀 Sviluppo Locale
```bash
# Installazione dipendenze
npm install

# Avvio server di sviluppo
npm run dev

# Build per produzione
npm run build
```
